学习通本地控制台 · Windows 部署包

使用方法
1. 将整个 ZIP 解压到本机磁盘（不要在压缩软件内直接运行）。
2. 双击 Setup.cmd，点击“一键安装并打开配置”。存在 D 盘时默认安装到 D:\Apps\ChaoxingConsole；无 D 盘时使用当前用户 LocalAppData\ChaoxingConsole，可自行改位置。首次自动打开“账号与登录”，请本人输入目标账号和密码并点击“加密保存”。
3. 新电脑若没有 MuMu，点击配置窗口的“安装 MuMu”，完成官方安装。该引导程序需要联网，可能要求管理员确认或系统重启；系统硬件虚拟化须可用。
4. 选择 MuMuManager.exe（一般在 MuMu\nx_main），实例编号默认 0，点击“安装 / 配对”。已有 MuMu 会优先检测；不要选择正在被其他任务控制的实例。
5. 点“通知权限”，在安卓中开启通知桥的通知使用权；点“打开学习通”，由本人用目标账号完成首次登录并打开 软件工程(唐班) 群。回到“账号与登录”，勾选账号确认，再点“核对首次登录 / 恢复”。
6. 点“检查并启动”。以后双击桌面“学习通通知控制台”即可一键启动模拟器、本地模型和群监看。

账号与自动重登
控制台中的“账号与登录”可更新目标账号和密码、开关自动重登。密码不会在设置窗口自动回显。
第一次登录由本人完成并核对。新目标账号保存后停止旧账号活动处理，需手动切换学习通账号并重新核对。
凭据保存在当前 Windows 用户 DPAPI 容器中，不进入模型、命令行或活动回执。加密绑定当前 Windows 用户，不能直接把该文件复制到其他电脑使用。
确认首次登录后，监看到账号密码登录页时先使用加密账密尝试一次。
学习通 7.0.4 原生账号密码页已适配；验证码、短信/扫码/单位等其他登录形式或未知布局交给本人处理。
密码错误、验证要求或提交后不能确认登录完成时暂停，不循环重试。本人完成登录回到 软件工程(唐班) 后，运行中的监看自动继续。
若启动接收前已遇到登录验证，完成验证后再次点击“启动接收”。每周自动结束和“一键全部停止”仍然有效。
不自动接受登录协议或完成验证码；若应用要求重新确认协议，请本人操作。

保留的设置
北京时间每周三、周五 18:00 自动启动，19:51 自动停止接收并关闭模拟器。
窗口里的“每周时段”可添加、修改、移除；保存后立即应用。
电脑需要开机并已登录 Windows；本版计划注册要求 Windows 时区为“北京时间 / China Standard Time”。
关闭控制窗口后接收仍继续；结束接收请点“一键全部停止”。
启动过程中也可点击此按钮取消。它结束本程序接收、模型、本次定时会话和选定 MuMu 实例，核验退出后显示已停止。
若没有其他 MuMu 实例运行，同时关闭 MuMu 主窗口及本次后台组件；共享 ADB 服务和虚拟化系统服务保留。
控制窗口保留，方便重新启动；手动停止取消当前时段运行，后续每周时段不变。

本包已移除旧网页轮询、网页登录/作业提交、旧定时入口及浏览器执行脚本。系统通知只记录提醒，练习和投票从目标群内卡片进入。

本包包含
Python 3.14 运行时及 Tk 窗口组件、Qwen3-4B-Instruct-2507 本地模型、llama.cpp Vulkan/CPU 运行库、
软件工程课件知识库、ADB、学习通 7.0.4 安装 APK、通知桥与页面读取器、MuMu 官方引导安装程序、VC++ 官方运行库。
本版监看目标：软件工程(唐班) 群内随堂练习（A～M，2～13 选项）和投票、模型选择提交、回执核对和回群监看。
启动及回群路径：打开学习通 → 底部“消息” → 顶部“通讯录” → “我加入的群聊” → 软件工程(唐班)。中英文括号兼容，其余群名完整匹配。
练习和投票处理器沿用此前 demo 验收版本；真实课程的新活动仍以当次学习通回执为准。其他通知或未适配布局不会因此获得新的自动提交权限。首次群基线不会自动补交历史活动。
显卡设备在首次配置中检测，优先已发现的独立显卡；没有 Vulkan 设备时使用 CPU，速度需在目标电脑实际验收。
模型检测失败时可先安装随包 VC++ 运行库。新电脑不需要安装 Python、Android SDK 或开发工具。

个人数据
本包包含个人课程知识库和已有课程/群授权设置，适合本人迁移部署。
未包含当前电脑的学习通登录态、账号密码、DPAPI 加密凭据、通知令牌、模型 API 密钥或活动历史数据库。
新电脑首次配对时重新生成本机令牌；登录由本人完成。原电脑的加密容器仍留在原目录。

更新与冲突
升级前请先停止接收，并关闭旧控制台、账号设置与首次配置窗口，再运行安装包。
重新安装到已有本程序目录时，仅迁移本机 Android 配对/群记录/时段、加密凭据、本地模型状态与部署配置；旧网页运行目录和浏览器绑定不导入；旧版本保留为同级 backup 目录。本版升级会将监看目标及投票范围迁移至软件工程(唐班)，保留原先自动提交开关；已关闭的开关不会被重新打开。
安装前发现其他目录拥有同名计划或桌面入口会停止，避免两套接收端冲突。
若要把本机旧目录迁移到新目录，先停止旧接收端，在旧控制台移除全部时段并保存，再重命名旧桌面入口。
新安装自动带入本包的周三/周五时段。不要同时运行两份控制台接收端。
卸载时先停止接收、在窗口清空每周时段并保存，再退出窗口；保留需要的 runtime 凭据/记录后删除安装目录和对应桌面入口。
