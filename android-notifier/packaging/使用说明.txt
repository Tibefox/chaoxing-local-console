# Windows 安装流程

1. 下载联网安装包 ZIP 与 SHA-256 校验文件。完整解压到本机磁盘（不要在压缩软件内运行）。首次运行 Setup.cmd 会下载约 2.5 GB 的模型并验证固定 SHA-256；请保持网络可访问 Hugging Face，准备至少 7 GB 可用空间。
2. 完整解压 ZIP，先停止接收并关闭旧控制台/首次配置窗口，再运行 `Setup.cmd`。升级使用原目录；新电脑无需单独安装 Python 或开发工具。
3. 点击“一键安装并打开配置”，确认安装目录。有 D 盘时默认 `D:\Apps\ChaoxingConsole`。
4. 没有 MuMu 时点击“安装 MuMu”，在官方网站下载并安装。管理员授权、虚拟化开启与重启由本人操作。选择 `nx_main/MuMuManager.exe`，实例默认 0。
5. 在 MuMu 应用中心搜索安装“学习通”。公开包不带学习通 APK；未安装时配对流程会提示先安装，然后重新点击“安装 / 配对”。
6. 在本机“账号与登录”输入账密并加密保存。本人登录学习通，完成协议、验证码等操作。
7. 点击“安装 / 配对”，然后“通知权限”，本人授予“学习通通知桥”通知使用权。
8. 学习通 → 消息 → 通讯录 → 我加入的群聊 → 软件工程(唐班)。账号设置中勾选本人确认，点“核对首次登录 / 恢复”。
9. 点“检查并启动”。确认显示模型就绪及正在监看目标群。可在“每周时段”编辑或取消时间；电脑须开机、保持唤醒并已登录 Windows。
10. 结束接收点击“一键全部停止”。关闭控制窗口会保留后台接收。

## 课件与群配置

`app/materials/slides.jsonl` 为 UTF-8 JSON Lines。每条记录包含 `file`、`slide`、`text`，可选 `notes`、`chart_text`、`alt_text`、`ocr_supplement`。自行替换示例前停止接收，重新启动后载入。
当前公开构建固定目标群，修改群名需同时修改源码 `group_config.py` 的 GROUP、`ui-reader/Reader.java` 的 GROUP、config 中的范围，并重新构建页面读取器和安装包。仅修改一个名字会导致群核验失败。

## 故障与数据

- CPU 回退可以使用，但性能需实测；模型错误时检查 `app/runtime/local-model/server.log`。
- 验证码、账号错误或未知登录页：由本人处理，重新核对后恢复。
- 账号容器绑定当前 Windows 用户，换电脑须重新保存，不能直接复制解密使用。
- 升级保留 Android 记录、账密、模型状态、部署配置及每周时段。旧网页记录不迁移，旧版本留同级备份。
- 验证完整性运行 `Verify.cmd`。首次实测先用演示活动核对回执，再启用实际时段。
