# Windows 安装与升级

当前定版为 [v0.1.6 联网安装包](https://github.com/Tibefox/chaoxing-local-console/releases/tag/v0.1.6)。完全干净 Windows 的完整验收尚未完成，详见 [验证范围](VERIFICATION-2026-11-06.md)。

## 首次安装

1. 准备 Windows x64，将系统时区设为北京时间（Windows 标识 `China Standard Time`）。电脑需要支持 MuMu 所需的虚拟化。准备至少 7 GB 安装空间，另为 MuMu、安卓实例和后续升级备份留空间。
2. 下载 `Chaoxing-Online-v0.1.6.zip` 与同名 `.sha256`，用 PowerShell `Get-FileHash .\Chaoxing-Online-v0.1.6.zip -Algorithm SHA256` 对照校验文件。完整解压到本机磁盘，不要在压缩软件内运行。
3. 双击 `Setup.cmd`。随包 Python 会先下载约 2.5 GB 的固定版本模型并核对 SHA-256，需要网络能访问 Hugging Face。失败后可再次运行；已完整且校验通过的模型会直接复用，未完成的下载不会作为可用模型。下载结束才进入安装窗口。
4. 点击“一键安装并打开配置”，确认目录。有 D 盘时默认 `D:\Apps\ChaoxingConsole`，否则使用当前用户 LocalAppData。无需单独安装 Python 或开发工具。
5. 在首次配置中点击“安装 MuMu”，通过官方网站安装；管理员授权、虚拟化配置和必要的重启由本人完成。选择安装后的 `nx_main\MuMuManager.exe`，实例默认 0。若本机缺少 VC++ 运行库，点击“安装 VC++ 运行库”并完成安装。
6. 在 MuMu 应用中心安装“学习通”。公开包不包含 MuMu 安装器或学习通 APK。配对提示学习通未安装时，安装后重新配对。
7. 在本机“账号与登录”保存目标账密；此时可以先关闭账号窗口。点击“安装 / 配对”，成功后点击“通知权限”，本人授予“学习通通知桥”通知使用权。
8. 打开学习通，由本人完成首次登录、协议和验证码。进入：消息 → 通讯录 → 我加入的群聊 → 软件工程(唐班)。重新打开“账号与登录”，勾选本人确认，点击“核对首次登录 / 恢复”。账号密码不应发送给他人或放进源码。
9. 点击“检查并启动”。它会核对配对、通知权限和目标群，并打开控制台自动启动接收。确认模型就绪、状态为“正在监看 软件工程(唐班)”。启动失败按界面提示处理，不要同时启动源码接收端。
10. 打开“每周时段”核对设置：新安装默认周三、周五 18:00–19:51（北京时间），可修改、删除或取消。自动运行需要电脑开机、保持唤醒且已登录 Windows，不能替代开机或唤醒功能。先用本人获授权的演示活动核对平台回执和回群。
11. 停止时点击“一键全部停止”，会结束本程序管理的接收、模型等子进程及 MuMu。只关闭控制窗口会保留后台接收；保留的每周时段仍可能在下次触发时启动，请同时取消不需要的时段。

## 原目录升级

先点“一键全部停止”，关闭旧控制台和首次配置窗口，再解压新版、运行 `Setup.cmd` 并选择原安装目录。不要把 ZIP 文件直接覆盖到安装目录。

升级保留账号容器、Android 记录及回执、模型运行配置、部署配置、每周时段和 `app/materials` 用户知识库；**已有空时段列表也保持为空**。旧网页运行数据不迁移。旧安装保留在同级备份目录，升级失败会尝试回滚。验收后再自行清理备份以释放空间。

v0.1.5 修复了升级可能用示例知识库替换用户课件的问题。此前版本若已覆盖资料，请先从同级旧安装备份取回 `app/materials`，不要把备份内的凭据上传到 GitHub。

若已有完整模型，可在解压目录的 PowerShell 中先运行以下命令复用，随后运行 `Setup.cmd`：

```powershell
.\payload\python\python.exe -I .\download_model.py "D:\Apps\ChaoxingConsole\models\chat-verified.gguf"
```

`Verify.cmd` 校验完整载荷，须在模型下载或复用完成后运行；下载前提示缺少模型是预期行为。

## 课件与群配置

`app/materials/slides.jsonl` 是 UTF-8 JSON Lines。每行包含 `file`、`slide`、`text`，可选 `notes`、`chart_text`、`alt_text`、`ocr_supplement`。公开包仅有原创示例，不能替代课程资料。停止接收后替换为有权使用的资料，重新启动后载入。

当前构建固定目标群为“软件工程(唐班)”，兼容全角括号。更换目标群须同时修改源码 `android-notifier/group_config.py` 的 GROUP、`android-notifier/ui-reader/Reader.java` 的 GROUP、config 中的范围，并重新构建页面读取器和安装包；仅改一个名字会导致群核验失败。

## 故障排查与验收

- 全部显示“群卡片待核验”：升级至当前版并重启接收端。安装器和接收端会修复配置目录继承权限；配置仍不可读时会显示具体文件错误。近期核验失败卡片会重试，已提交活动有去重保护。
- 判断题：支持页面实际的两项对错、正确错误、是否或 true/false；单选支持 A～M。多选、多题合页或未知布局不会冒充已支持，应查看原因和本地记录后适配。
- 提交后回执暂未出现：脚本会重新核对平台状态；不要仅凭点击记录认定成功，也不要手动重复点击提交。成功需平台已提交回执，再确认回到目标群。回执不代表教师判分正确。
- 学习通退出：安卓已启动、停在已识别 MuMu 桌面且学习通进程消失时，脚本会恢复通知转发并重新打开、回群。模拟器整体退出、系统未启动或停在其他应用时不属于这个恢复路径。
- CPU 回退可用，但速度需在目标电脑实测。模型日志在 `app/runtime/local-model/server.log`；监看状态在 `app/runtime/android/group-watch.json`。
- 过程追踪存于 `app/runtime/android/events.sqlite3` 的 `group_activity_trace`，活动页面快照存于 `app/runtime/android/activity-traces`。这些是本机私有数据，排查前脱敏，不上传公开仓库。旧版本未记录的页面和时间不能事后补证。
- 验证码、账号错误或未知登录页由本人处理，重新核对后恢复。DPAPI 容器绑定当前 Windows 用户，换电脑须重新保存账密。
